## 使用说明

1. 在即梦中选择 **1:1 比例**，逐条粘贴提示词生成
2. 导出为 JPG，命名为 `ach_<id>.jpg`
3. 放入 `app/src/assets/achievements/` 目录
4. 同名文件直接覆盖旧版简笔图标

**弱卡类快捷方式**：复制通用模板，替换 `[INSERT CARD THEME HERE]` 和 `[SUIT COLOR]` 即可批量出图，保持视觉一致性。
