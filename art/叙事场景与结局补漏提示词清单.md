## 落位自查

全部完成后在 `app/` 目录执行：

```bash
npm run build
```

构建即校验；场景图/结局图按文件名自动接入：
- 场景图：进入对应场景时以衬底呈现（`.scene-bg`）
- 结局图：结局结算页顶部大图 + 图鉴详情页
- 未落位的图自动降级为纯文字，不影响游戏
