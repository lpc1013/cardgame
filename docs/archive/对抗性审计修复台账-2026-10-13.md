### 视觉/无障碍篇（同轮一并处理）

- 全局 `* { user-select: none }` 只放行 `.log-text/.choice-text/.dialogue-text`——这三个类名在 `.ts/.tsx` 里 grep 命中数为 **0**，即阅读文字从来没被放开过。现在默认放开，只在按钮 / 卡面 / 牌桌 / 缩略图条上关闭。实测：剧情行 `user-select: auto`、按钮 `none`。
- 封面大图入口原先是 `<img onClick>`，键盘与读屏到不了。改为真 `<button class="cover-img-hit">` + `aria-label="展阅封面大图：…"`，按钮 `display:contents` 保持图片在 `.cover-main` 里的绝对定位铺满，焦点环画在图片本身（`:focus-visible .cover-img { outline }`）。既然大图入口能用键盘点开，出口也补了真「合卷」按钮，不再只靠"点按任意处"。
- PWA 两档离线口径写进设置面板并接线可点：「基础离线可玩」由 precache 的 js/css/html 保证（剧本数据在 `scenario-data` chunk 里）；「插画完整离线」新增**全部预取**按钮，清单来源是 `ui/art.ts` 各 glob 的实际命中值（`allArtUrls()`），不手写名单。
