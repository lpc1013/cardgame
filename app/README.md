# 帝成观止 · 叙事卡牌剧本引擎

中式权谋题材的叙事卡牌游戏。重文本、重抉择、多结局，极简文字 UI + 双规则卡牌对局。
单人开发流程产物：剧本全部表格数据驱动，代码只负责解释执行。

## 运行

```bash
npm install
npm run dev       # 开发预览（浏览器打开终端显示的地址）
npm run build     # 生产构建 → dist/
npm run preview   # 本地预览 dist/
```

- **技术栈**：Vite + React + TypeScript，无外部美术/音频素材
- **PWA**：构建后即为可离线运行的网页应用（Service Worker 自动注册），手机浏览器打开后可"添加到主屏幕"
- **部署**：`npm run build` 后将 `dist/` 整个目录上传至任意静态托管（GitHub Pages / Vercel / Netlify），无需额外配置（`base: './'`）

## 玩法结构

- **案件模式**（5 案）：调查取证 → 线索卷宗（真/伪/核心三档）→ 结案陈词拣选 → 定谳抉择。每案结构不同：双线 A/B、八段探查、三层套盒暗线、双层真相、开放调查枢纽。
- **叙事模式**（8 篇）：多视角章节剧 + 道德分支 + 走马灯回响。选择跨章节、跨视角互相影响。
- **帝国系统**（跨剧本元进度）：解锁结局奖励墨铤（每个 20）；顶栏商市可购开局加成（初始银两/气力/行动力/起手抽牌，出征时勾选消耗）与主题外观（全局配色）；行囊为跨剧本仓库，物品卡可存入并在出征时携带至多 2 件到别的剧本；首页为封面轮播选本（13 张专属封面 + 结局角标）。案件链式解锁：前案任一结局解封下一案，封印案显示剪影+封条，可花 60 墨铤提前破封；已有进度/结局的剧本不受锁限。
- **双规则卡牌对局**（四色体系：策/器/势/隐，相克环 策克势·势克器·器克隐·隐克策）：
  - 情绪匹配制（谈判/试探）：同色=共鸣，克色=破防，被克=大失言，错色=失言；v2 出牌不耗行动力
  - 气力压制制（对质/战斗）：比点伤气，克敌牌色+1/被克-1，势牌翻倍反噬；不对称配置可做出"必败死局"或"唯一生还线"
- **卡牌系统 v2**（五个案件全部接入，标题带 ✦）：四层卡（成术/物品/人物/资源）、三档稀有度、12 张编组卡组、市集（买卡/卖卡/卡包/赌坊骰宝）、三选一翻牌、卡牌即钥匙的剧情分支、烧卡改写剧情、对局手牌制（起手抽4/每轮补4/牌库洗回；人物卡场外被动；行动力仅压制制耗）、棋局残局与宴会行令小游戏、卡牌图鉴（？？？收集点亮）
- **系统**：自动存档（继续上次）、结局图鉴、剧情树（已探明/未探明分支可视化）、程序化音效（WebAudio，可开关）

## 内容管线（写新剧本不改代码）

剧本数据在 `src/data/*.ts`，亦可全程用 Excel 维护：

```bash
node scripts/content.mjs export            # 导出所有剧本为 content/*.xlsx 模板（六张表）
node scripts/content.mjs import <file.xlsx> <name>   # 从 xlsx 生成 src/data/<name>.gen.ts
```

表格规范见 [`docs/SCHEMA.md`](docs/SCHEMA.md)：总表 / 场景表 / 选项表 / 卡牌表 / 线索表 / 对局表。
模块接口 / 数据流 / 外部依赖 / 对接规范见 [`docs/INTEGRATION.md`](docs/INTEGRATION.md)。

生成 `.gen.ts` 后在 `src/App.tsx` 的 `SCENARIOS` 数组里加一行 import + 注册即可上架。

## 目录结构

```
src/
  engine/
    types.ts     # 剧本数据 Schema（六类实体）
    runtime.ts   # 叙事运行时（旗标/数值/线索/条件）
    duel.ts      # 双规则对局引擎（含博弈：虚张/读牌/蓄势/破招）
    minigames.ts # 场景化小游戏（棋局残局 / 宴上行令 / 骰宝）
    save.ts      # 存档 / 结局图鉴 / 剧情树记录 / 帝国元进度 / 全局卡注册表
    sfx.ts       # 程序化音效（WebAudio）
  data/          # 剧本数据（13 部）+ cardThemes(门类) + empireShop(帝国商市)
  components/    # 剧情树视图（TreeView）
  App.tsx        # 主界面（标题/阅读/对局/复盘/结局）+ 各面板组件
  app.css        # 全局样式（含 PWA 主题变量）
content/         # xlsx 剧本模板（内容管线产物）
docs/SCHEMA.md   # 表格规范（Excel ⇄ 数据）
scripts/
  content.mjs            # Excel ⇄ 数据 管线
  gen_art_prompts.mts    # 美术提示词生成（甲·去字化 + 乙·双轴门类）
  verify.mts             # 回归验证套件（build 前置门禁）
```

## 验证方式

无独立测试框架；冒烟测试直接执行引擎模块（Node 类型剥离）：

```bash
node --experimental-strip-types <脚本>
```

已验证项：`npm run verify`（已接入 build）按真实 UI 合同穷举全部对局——可胜局断言可胜、
设计性必败局（8 处败线演出）断言不可胜；情绪制出牌后反馈文案非空断言（防「清 lastResult」
类回归）；裸卡组四色覆盖检查；场景跳转可达、复盘判定门控、存档恢复（v3）、结局图鉴与
剧情树闭环、PWA 离线资源、浏览器端到端通玩。
