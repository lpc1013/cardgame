# 帝成观止 · 叙事卡牌剧本引擎

中式权谋题材的叙事卡牌游戏。重文本、重抉择、多结局，极简文字 UI + 双规则卡牌对局。
单人开发流程产物：剧本全部表格数据驱动，代码只负责解释执行。

## 运行

```bash
npm install
npm run dev       # 开发预览（浏览器打开终端显示的地址）
npm run build     # 生产构建 → dist/
npm run preview   # 本地预览 dist/
```

- **技术栈**：Vite + React + TypeScript，无外部美术/音频素材
- **PWA**：构建后即为可离线运行的网页应用（Service Worker 自动注册），手机浏览器打开后可"添加到主屏幕"
- **部署**：`npm run build` 后将 `dist/` 整个目录上传至任意静态托管（GitHub Pages / Vercel / Netlify），无需额外配置（`base: './'`）

## 玩法结构

- **案件模式**（5 案）：调查取证 → 线索卷宗（真/伪/核心三档）→ 结案陈词拣选 → 定谳抉择。每案结构不同：双线 A/B、八段探查、三层套盒暗线、双层真相、开放调查枢纽。
- **叙事模式**（7 篇）：多视角章节剧 + 道德分支 + 走马灯回响。选择跨章节、跨视角互相影响。
- **双规则卡牌对局**：
  - 情绪匹配制（谈判/试探）：威/理/利/情四色；同色=共鸣，对色（威↔理、利↔情）=破防，错色=失言
  - 气力压制制（对质/战斗）：比点伤气，威牌翻倍反噬；不对称配置可做出"必败死局"或"唯一生还线"
- **卡牌系统 v2**（五个案件全部接入，标题带 ✦）：四层卡（成术/物品/人物/资源）、三档稀有度、12 张编组卡组、市集（买卡/卖卡/卡包/赌坊骰宝）、三选一翻牌、卡牌即钥匙的剧情分支、烧卡改写剧情、对局手牌制（行动力/道具/人物被动）、棋局残局与宴会行令小游戏、卡牌图鉴（？？？收集点亮）
- **系统**：自动存档（继续上次）、结局图鉴、剧情树（已探明/未探明分支可视化）、程序化音效（WebAudio，可开关）

## 内容管线（写新剧本不改代码）

剧本数据在 `src/data/*.ts`，亦可全程用 Excel 维护：

```bash
node scripts/content.mjs export            # 导出所有剧本为 content/*.xlsx 模板（六张表）
node scripts/content.mjs import <file.xlsx> <name>   # 从 xlsx 生成 src/data/<name>.gen.ts
```

表格规范见 [`docs/SCHEMA.md`](docs/SCHEMA.md)：总表 / 场景表 / 选项表 / 卡牌表 / 线索表 / 对局表。

生成 `.gen.ts` 后在 `src/App.tsx` 的 `SCENARIOS` 数组里加一行 import + 注册即可上架。

## 目录结构

```
src/
  engine/
    types.ts     # 剧本数据 Schema（六类实体）
    runtime.ts   # 叙事运行时（旗标/数值/线索/条件）
    duel.ts      # 双规则对局引擎
    save.ts      # 存档 / 结局图鉴 / 剧情树记录
    sfx.ts       # 程序化音效（WebAudio）
  data/          # 剧本数据（12 部）
  components/    # 剧情树视图
  App.tsx        # 主界面（标题/阅读/对局/复盘/结局）
content/         # xlsx 剧本模板
docs/SCHEMA.md   # 表格规范
scripts/content.mjs  # Excel ⇄ 数据 管线
```

## 验证方式

无独立测试框架；冒烟测试直接执行引擎模块（Node 类型剥离）：

```bash
node --experimental-strip-types <脚本>
```

已验证项：全部剧本场景跳转可达、双对局规则可解性（含截杀战"唯一生还线"穷举）、
复盘判定门控、存档恢复、结局图鉴与剧情树闭环、PWA 离线资源、浏览器端到端通玩
（驸马案 A 线全流程实测：叙事→对局→复盘→结局→图鉴）。
