## 其他剧本的补充需求（供你出图时参考）

- **案件五案**：大理寺公堂（匾额「明刑弼教」）、卷宗/线装书特写、市集夜景、囚牢烛火——通用度最高
- **驸马案**：如意酒家雅间（碎酒罐/烛台/短匕）、黄锦密信与银票特写
- **丝绸案**：桑田连片、织坊织机、暗纹云锦特写（金线纹样）、河堤黑土
- **自燃案**：白衣书生临窗剪影、凸面镜片聚光、檐下织妇
- **秦淮案**：画舫夜灯、双层水痕小舟、雨中贡院
- **孤品卡面**（14 张）优先级最高——它们是图鉴里的“镇馆之宝”

## 规格（建议）

- 卡面：竖版 3:4，512×682 以上；场景插图：16:9 横版

- 案件卡牌配色建议沿用现有稀有度色：凡=灰白 / 良=金 / 孤品=朱红边框
